# assistant-bot

Личный помощник в Telegram: заметки, задачи с подзадачами, напоминания (разовые и повторяющиеся), картинки и открытки, схемы по описанию и по репозиторию GitHub, режим изучения языка (испанский по умолчанию). Движок (транспорт Gemini с хеджированием, реестр инструментов, цикл «модель → инструменты → ответ», очередь на чат, graceful shutdown) перенесён из бота Айман.

## Запуск

```bash
npm install
cp .env.example .env   # заполнить токены
npm start              # long polling, вебхук не нужен
```

На Windows можно просто дважды кликнуть `start-bot.cmd` — окно с логом, закрыл окно = остановил бота.

Первый, кто напишет боту, становится владельцем (если `OWNER_TELEGRAM_ID` пуст). Остальным бот отвечает отказом.

- `npm run dev` — то же с автоперезапуском при правках.
- `npm run chat -- "напомни завтра в 9 позвонить маме"` — ход агента в консоли без Telegram (своя база `data/chat-cli.sqlite`, файлы в `data/out`).
- `npm test`, `npm run typecheck`.

## Ключи (.env)

| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `GEMINI_API_KEY` | ключ Google AI Studio; `GEMINI_MODEL` (3.5-flash) и `GEMINI_FAST_MODEL` (3.5-flash-lite) |
| `CF_ACCOUNT_ID`, `CF_API_TOKEN` | Cloudflare Workers AI (FLUX) — картинки; без них работает запасной Pollinations с водяным знаком |
| `DEFAULT_TIMEZONE` | зона до того, как владелец скажет свою (`/tz Europe/Moscow`) |

## Как устроено

```
src/
  main.ts               старт: Telegram polling + планировщик + graceful shutdown
  config.ts             .env
  llm/gemini.ts         ModelTransport: function-calling, эхо thoughtSignature, ретраи, хедж между моделями
  llm/loop.ts           цикл инструментов
  tools/                notes, tasks, reminders, memory (факты, часовой пояс), media (картинки/открытки/схемы)
  agent/                системный промпт и один ход агента (история ↔ SQLite, outbox файлов)
  telegram/             Bot API, long polling, нормализация апдейтов, кнопки, роутинг
  scheduler/            напоминания: проверка каждые 15 с, повторы, «Готово / +10 мин / +1 час / Завтра»
  images/, diagrams/    Cloudflare FLUX + Pollinations; наложение текста (resvg); Graphviz (viz.js); GitDiagram + kroki
  learn/                изучение языка: урок дня (Gemini JSON → банк из 6 тем), карточки Лейтнера, разговор с «носителем», озвучка
  db/                   node:sqlite, схема и запросы
  views.ts              детерминированные экраны кнопок меню
```

Модель: основная `gemini-3.5-flash` (thinking low). Если она не ответила за 3,5 с или вернула 429/503, параллельно стартует `gemini-3.5-flash-lite`, побеждает первый ответ. После сбоя основной минуту обе стартуют сразу.

## Изучение языка (кнопка «🇪🇸 Испанский», /learn)

Перенос сайта «¡Habla!» в чат.

- **Урок дня** (~15 мин): словарь с озвучкой, грамматика с таблицей, разговорные фразы, аудирование (голосовое без текста → вопрос с вариантами), упражнения (вставить слово, выбрать, перевести — перевод проверяет модель), тест из 5 вопросов. Тема — та, что проходили реже всего (6 тем: приветствия, распорядок дня, еда, семья, путешествия, погода и досуг). Содержимое генерирует Gemini (lite, JSON); если модель недоступна — встроенный банк. Фокус (грамматика / разговор / аудирование) и уровень A1–B1 в настройках.
- **Карточки**: ошибки из урока попадают в колоду автоматически, вручную — «карточка: la mesa — стол», пачкой — «сгенерируй 20 карточек про еду» (модель подбирает частотную лексику уровня). Система Лейтнера: 5 коробок, интервалы 0/1/3/7/16 дней. Повторять можно в чате (кнопки) или в **Mini App** — тренажёр со свайпами и озвучкой (`webapp/`, хостится на GitHub Pages, деплой через `.github/workflows/pages.yml`). Колода уходит в приложение в URL (`#d=base64url`), результаты возвращаются боту через `Telegram.WebApp.sendData`, бэкенд не нужен. Адрес — `WEBAPP_URL` в .env.
- **Разговор**: Lucía из Мадрида отвечает короткими репликами на изучаемом языке с вопросом в конце, ошибки комментирует по-русски в скобках. Голосовые ученика расшифровываются, реплики озвучиваются. Выход — «стоп», /stop или кнопка; в конце короткий разбор.
- Озвучка: Google Translate TTS (MP3 как голосовое), запасной — Gemini TTS.
- Серия дней (streak) растёт за урок в день. Сессия урока хранится в SQLite и переживает рестарт.

Схемы репозиториев берутся с gitdiagram.com только уже сгенерированные; для нового репо бот даёт ссылку «открой один раз» и сам присылает схему, когда она появится (ждёт до 10 минут).
